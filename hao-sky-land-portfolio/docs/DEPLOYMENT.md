# Deployment checklist

1. Confirm `npm run build` succeeds locally.
2. Push the `main` branch to GitHub.
3. In repository Settings → Pages, select **GitHub Actions**.
4. Watch the Actions tab until `Deploy to GitHub Pages` completes.
5. Open the URL shown by the deploy job.
6. Test mobile, language switch, navigation, links and keyboard access.
7. Add a custom domain only after DNS and domain ownership are verified.
